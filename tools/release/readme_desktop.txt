Buckshot Roulette, the PS Vita port, on Windows
===============================================

1. Make the game data with bsht-extract (a separate download) from your own
   copy of Buckshot Roulette v2.2.0 hotfix 6.
2. Copy its bsht-data\game folder here, next to bsht_desktop.exe, so that
   game\manifest.json sits beside the exe.
3. Run bsht_desktop.exe.

Without the game folder it shows a screen saying where the data should be.
Saves go to save\ here. The console window is the log.

Mouse and keyboard work as in the original; a controller works too.

Source, build steps and the licence: https://github.com/voidchecksam/BuckshotRoulettePortable-BSHT
